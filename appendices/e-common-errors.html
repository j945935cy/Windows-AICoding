Appendix E

初學者常見錯誤清單

HTML

  • CSS 檔名寫錯
  • JavaScript 沒有載入
  • id 和 JavaScript 選取名稱不一致

CSS

  • class 名稱不一致
  • 固定寬度導致手機版超出畫面
  • 樣式被後面的規則覆蓋

JavaScript

  • querySelector 找不到元素
  • 改了資料但沒有重新渲染畫面
  • localStorage 忘記 JSON 轉換

除錯順序

  1. 確認檔案有儲存
  2. 重新整理瀏覽器
  3. 打開 Console
  4. 做最小修改
  5. 再次測試
