Appendix F

AI Coding 術語表

整理本書常出現的 AI coding、前端與除錯名詞。

AI Coding

用 AI 協助規劃、產生、修改、解釋與除錯程式碼的工作方式。

Prompt

交給 AI 的任務描述，通常包含目標、限制、範圍、輸出格式與完成標準。

HTML / CSS / JavaScript

HTML 負責結構，CSS 負責樣式，JavaScript 負責互動。

DOM

瀏覽器把 HTML 轉成可被 JavaScript 操作的物件結構。

localStorage

瀏覽器提供的本機儲存空間，可以保存少量文字資料。

State

程式目前保存的狀態，例如待辦清單陣列、目前篩選分類、計算機目前數字。

Debug

找出錯誤原因並修正的過程。

Refactor

在不改變功能的前提下整理程式碼，讓程式更清楚、更容易維護。
