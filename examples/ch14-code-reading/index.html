Chapter 14 Example

讀懂 AI 產生的程式碼

先理解檔案分工與事件流程，再開始修改。

HTML：先找頁面區塊

觀察頁面有哪些主要區塊，例如 hero、toolbar、note-panel。先理解內容結構，不急著改樣式。

<section class="hero">
  <h1>讀懂 AI 產生的程式碼</h1>
</section>

CSS：用 class 對照畫面

找到 HTML 裡的 class，再到 CSS 中搜尋同名選擇器，理解哪些樣式控制間距、顏色與排列。

.note-panel {
  padding: 24px;
  border: 1px solid #e5e7eb;
}

JavaScript：追蹤事件流程

先找 addEventListener，再看事件發生後改了哪些 class 或文字。

button.addEventListener("click", () => {
  showPanel(button.dataset.target);
});
