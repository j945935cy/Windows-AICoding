Chapter 14

如何閱讀與修改 AI 產生的程式碼

建立一套讀碼方法：先看檔案結構，再看 HTML、CSS、JavaScript 的分工，最後才開始修改。

讀碼順序

  1. 先看專案檔案。
  2. 再看 HTML 區塊。
  3. 再看 CSS class。
  4. 再看 JavaScript 事件流程。
  5. 最後只做一個小修改並測試。

Prompt 範例

請先不要修改程式。請閱讀這三個檔案，說明 index.html、style.css、script.js 各自負責什麼，並列出主要區塊。
