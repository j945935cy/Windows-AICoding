# 附錄 A：Prompt 終極速查表

在實際開發中，初學者常常會遇到不知道如何跟 AI 溝通的窘境。本附錄為你整理了在不同開發階段中最實用、最防呆的「黃金 Prompt 模板」。你可以將這些模板存入你的筆記本，隨時複製修改。

## 1. 規劃期 (Planning)

在專案開始前，先透過 AI 幫你釐清需求，而不是直接讓它寫程式碼。

### 需求拆解與架構規劃
```text
我想做一個 [你的網站主題，例如：個人作品集]。
請先不要寫任何程式碼。請先幫我回答「需求拆解表」的 5 個核心問題：

1. 這個網頁是給誰用的？
2. 使用者進來第一眼要看到什麼？
3. 頁面需要哪些區塊？
4. 哪些地方需要互動？
5. 建議的實作步驟？
```

### 專案分工詢問
```text
我現在要建立一個前端專案。請告訴我針對這個專案，我的 index.html、style.css 和 script.js 分別應該負責哪些具體的任務？
```

## 2. 開發期 (Coding)

在要求 AI 產出程式碼時，最重要的心法是「限制技術」、「限制範圍」與「提供範例」。

### 限制技術與範圍 (防幻覺)
```text
請幫我寫一個導覽列的結構。
技術限制：只能使用純 HTML 與 CSS，絕對不能使用 Tailwind 或任何框架。
輸出要求：只輸出 HTML 與 CSS 程式碼，不需要解釋原理。
```

### 提供現有範例 (Few-shot Prompting)
```text
這是我目前的卡片 HTML 結構：
[貼上你的 HTML 程式碼]

請參考我目前的命名風格與層級，幫我再產生 2 張內容不同的卡片程式碼。
```

### 角色扮演 (提升品質)
```text
你現在是一位擁有 10 年經驗的資深前端工程師。
請檢閱我寫的這段 JavaScript 程式碼，並指出哪裡有潛在的問題或寫得不好的地方？
[貼上你的 JS 程式碼]
```

## 3. 除錯期 (Debugging)

遇到錯誤時，切忌只丟一句「壞掉了怎麼辦」，必須提供完整的上下文。

### 完美除錯模板
```text
我遇到了一個錯誤，請幫我除錯。

1. **我的目標是**：[例如：點擊清空按鈕後，待辦清單應該被清空]
2. **目前的行為是**：[例如：點擊按鈕完全沒反應，但 Console 有跳紅字]
3. **Console 顯示的錯誤訊息**：[貼上完整的紅色錯誤訊息]
4. **相關的程式碼如下**：
[貼上 HTML 與 JS 的相關片段]
```

### 請求解釋
```text
我不懂為什麼你剛剛加的 `e.preventDefault()` 可以修復這個 bug。
請用初學者能聽懂的白話文，並舉一個生活中的例子來解釋它的原理。
```

---

> **[小提示]**
> 在使用這些 Prompt 時，請永遠記得：你是專案負責人，AI 只是你的協作夥伴。當 AI 給出的結果不符合預期時，請先檢查你的 Prompt 是否足夠清晰？是否給足了上下文？這才是精進 AI Coding 技巧的最快路徑。
