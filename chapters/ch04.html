Chapter 04

HTML 基礎與頁面結構

HTML 負責網頁內容與結構。這一章會用語意清楚的標籤組出一個基本頁面。

核心觀念

HTML 不是拿來設計樣式的工具，它的任務是描述內容是什麼。標題用標題標籤，段落用段落標籤，導覽用 nav，主要內容用 main。

常用標籤

  • header、nav、main、section、footer
  • h1 到 h6、p、ul、li、a

Prompt 範例

請只使用 HTML，幫我建立一個語意清楚的學習筆記頁。內容包含頁首、導覽列、主要內容、三個學習目標、三則筆記卡片和頁尾。不要加入 CSS 和 JavaScript。
