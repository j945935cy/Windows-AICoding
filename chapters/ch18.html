Chapter 18

下一步學什麼

完成 HTML、CSS、JavaScript 與 Codex 入門後，下一步要圍繞作品繼續學 Git、API、部署與框架。

建議順序

  1. Git 與 GitHub：保存每一次可運作版本。
  2. API 基礎：讓網頁取得外部資料。
  3. 部署：把作品放到線上。
  4. 前端框架：在基礎穩定後再學。
  5. 作品集深化：把既有作品改得更完整。

Prompt 範例

我已經完成一本 AI coding 入門書的 HTML、CSS、JavaScript 專案。請幫我規劃下一階段 4 週學習路線，主題包含 Git/GitHub、API、部署、作品集改版。請每週給我一個明確成果。
