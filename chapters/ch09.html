Chapter 09

專案一：個人介紹網站

把 HTML、CSS、JavaScript 整合成第一個完整小專案，用來介紹自己、展示技能與放上作品連結。

你會完成什麼

  • 頁首導覽列與 Hero 自我介紹區。
  • 技能列表、作品卡片與聯絡區。
  • 手機版選單與作品卡片互動。

專案檔案

examples/ch09-personal-site/
  index.html
  style.css
  script.js

實作順序

  1. 先用 HTML 建立完整內容。
  2. 再用 CSS 設計清爽、留白充足的版面。
  3. 補上手機版導覽選單。
  4. 用 JavaScript 做作品卡片互動。

Prompt 範例

請只修改 style.css，讓這個個人介紹網站呈現清爽、留白充足、淺藍紫色調的視覺風格。卡片圓角不要超過 8px，手機版要一欄排列。

範例檔案

本章範例在 examples/ch09-personal-site/。

進階挑戰 (Bonus Challenge)

當你完成基礎版本後，請挑戰加入深色模式 (Dark Mode) 切換功能：

  • 在右上角新增一個「切換主題」按鈕。
  • 用 CSS 變數定義淺色與深色背景/文字顏色。
  • 用 JavaScript 監聽點擊，並在 <body> 切換 dark class，同時存入 localStorage。
