Chapter 08

AI Coding 的需求拆解方法

把模糊想法拆成 Codex 能執行的小任務，先規劃，再請 Codex 寫程式。

好的任務包含什麼

  • 目標：我要做什麼。
  • 使用者：誰會用。
  • 技術限制：只能用什麼。
  • 修改範圍：這次只動哪裡。
  • 驗收標準：怎樣才算完成。

Prompt 模板

我要做一個 [網站類型]，使用者是 [目標讀者]。
請先不要寫程式，先幫我拆解：
1. 頁面區塊
2. 需要的 HTML 結構
3. 需要的 CSS 版面
4. 需要的 JavaScript 互動
5. 建議的實作順序
技術限制：只能使用 HTML、CSS、JavaScript。
