Chapter 12

專案四：圖片展示頁

用 CSS Grid 建立圖片網格，並用 JavaScript 實作分類篩選與放大視窗。

你會完成什麼

  • 圖片網格與分類按鈕。
  • 點擊卡片開啟 modal。
  • 關閉按鈕、背景與 Escape 關閉。

專案檔案

examples/ch12-gallery/
  index.html
  style.css
  script.js

核心觀念

圖片展示頁的重點是 CSS Grid 與狀態切換。這個範例用 CSS 漸層色塊作為縮圖，讓你專注在版面與互動。

Prompt 範例

請只修改 script.js，替圖片展示頁加入分類篩選與 modal。點擊分類按鈕時過濾卡片；點擊卡片時開啟 modal；點擊關閉按鈕、背景或 Escape 時關閉 modal。

範例檔案

本章範例在 examples/ch12-gallery/。

進階挑戰 (Bonus Challenge)

當你完成基礎版本後，請挑戰加入平滑過場動畫 (CSS Transitions)：

  • 切換分類時，被隱藏的圖片不要瞬間消失，而是透過 opacity 與 transform: scale() 淡出縮小。
  • 使用 JavaScript 的 setTimeout 或監聽 transitionend 事件，等動畫結束後再真正給予 display: none。
